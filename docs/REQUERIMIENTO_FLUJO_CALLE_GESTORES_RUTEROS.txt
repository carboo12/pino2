⚙️ Lista: "Proceso"
1. ADMINISTRADOR
Módulo: Plataforma Web (React 19) — Frecuencia: Eventual/Diario
- Proceso A (Alta de Personal): Configuración > Gestión de Usuarios → completar datos → asignar rol exacto → guardar (contraseña encriptada con Argon2)
- Proceso B (Autorización de Emergencia): recibe alerta de proceso bloqueado → revisa incidente → Aprueba/Rechaza (firma digital)

2. JEFE / ENCARGADO DE BODEGA CENTRAL
Módulo: Plataforma Web (React 19) — Frecuencia: Diario/Continuo
- Proceso A (Factor X en productos): Catálogo > Nuevo Producto → SKU, precios → activa "¿Se controla en Bultos?" → define Unidades por Bulto (X) → guarda (constraint X > 1)
- Proceso B (Liquidación de Ruta): recibe al Rutero → sistema cruza Carga Inicial − Facturas Entregadas = Mercancía a Retornar → valida reporte del Auxiliar → Aprueba y Cierra

3. AUXILIAR DE RECEPCIÓN Y DESPACHO
Módulo: Web/Terminal de Almacén — Frecuencia: Diario/Piso
- Proceso A (Recepción de compras): ingresa proveedor/orden → digita Bultos y Unidades → valida código de barras → confirma (sistema convierte a Unidades Totales Base)
- Proceso B (Armado de carga): abre orden de despacho consolidada → prepara mercancía → checklist con el Rutero → marca "Cargado y Entregado"

4. ANALISTA / AUDITOR DE INVENTARIOS
Módulo: Plataforma Web — Frecuencia: Diario/Periódico
- Proceso A (Arqueo/Conteo ciego): genera evento por zona → cuenta sin ver stock lógico → sistema compara con movements → genera Reporte de Discrepancia si hay diferencias
- Proceso B (Ajuste de Kárdex): selecciona producto → indica motivo y cantidad → envía solicitud a authorizations (queda Pendiente)

5. GESTOR DE VENTAS (Preventista)
Módulo: App Android Flutter + Drift/SQLite — Frecuencia: Diario en Campo
- Proceso (Toma de pedidos offline): sincroniza catálogo/clientes/stock → selecciona cliente en ruta → busca producto (stock "50 Bultos/10 Unidades") → digita Bultos y Unidades (cálculo reactivo) → guarda pedido local (Outbox Pattern al recuperar red)

6. RUTERO / REPARTIDOR
Módulo: App Android Flutter + Impresora Bluetooth — Frecuencia: Diario en Campo
- Proceso A (Recepción de carga): acepta carga del día → revisa resumen (Bultos/Unidades) → firma recepción digital
- Proceso B (Entrega y cobro): selecciona cliente → confirma entrega total o parcial/rechazo (genera devolución en tránsito) → registra pago → convierte en factura → imprime comprobante
- Proceso C (Cierre de ruta): finaliza ruta → entrega mercancía no vendida al Auxiliar y efectivo al Cajero → envía resumen de liquidación

📝 Lista: "Tareas"
Tarjeta: "tareas de asignacion para Gestor de ventas y rutero"

1. Creación de rutas — se crean en Web: Logística y Comercial > Definición de Rutas. Dos tipos: Rutas de Ventas (Preventa) y Rutas de Reparto (Entrega).

2. Asignación de clientes al Gestor — la hace el Jefe de Bodega o Supervisor Comercial:
- Se crea la Ruta Comercial → se vinculan clientes → se asigna al Gestor → sincronización a la App
- Reasignación de emergencia: si un Gestor no puede atender, se reasignan sus clientes a otro Gestor vía "Reasignación Express"

3. Asignación de rutas al Rutero — la hace el Jefe de Bodega al consolidar pedidos:
- Gestores levantan pedidos → Jefe de Bodega filtra por zona y arma "Carga de Camión" → asigna al Rutero → Auxiliar arma la carga física → App del Rutero recibe su mapa de entrega
- Reasignación de entrega: si el Rutero tiene una avería, se transfiere la carga a otro Rutero disponible
