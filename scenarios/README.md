# Escenarios de Simulación — Pino2 Los Pinos Central

## Metodología

Este conjunto de escenarios describe situaciones reales que ocurren en una tienda de distribución Nicaragüense operando con el sistema Pino2 en "Los Pinos - Central". Cada escenario sigue el formato:

- **Rol:** Quién ejecuta la acción (cajero, bodeguero, rutero, administrador, dueño)
- **Duración:** Tiempo estimado de la operación real
- **Descripción:** Contexto realista de una tienda de distribución en Nicaragua
- **Precondiciones:** Estado del sistema antes del escenario
- **Pasos:** Secuencia de acciones, incluyendo llamadas API
- **Resultado esperado:** Comportamiento correcto del sistema
- **Variante:** Qué podría salir mal y cómo manejarlo

Los escenarios cubren todas las áreas operativas: ventas, inventario, pedidos, caja, clientes, rutas, empleados, tecnología y datos. Se incluyen escenarios integrales que abarcan operaciones completas.

## Cobertura geográfica

Las simulaciones reflejan la operación en Managua y rutas hacia León, Granada, Masaya, Chinandega, Matagalpa, Jinotega, Estelí, Rivas, Carazo, Boaco, Chontales y Río San Juan.
