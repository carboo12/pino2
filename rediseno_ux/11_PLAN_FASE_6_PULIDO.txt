TAREA 6.4 — Audit Final
================================================================================

TIEMPO: 1.5 horas

CHECKLIST:

  CONSISTENCIA VISUAL:
  [ ] Colores primarios coinciden entre web y Flutter
  [ ] Tipografía Inter funciona en ambas plataformas
  [ ] Border radius es consistente (12px buttons, 16px cards)
  [ ] Spacing es consistente (4px grid)

  [ ] Login se ve bien en mobile (320px)
  [ ] Login se ve bien en tablet (768px)
  [ ] Login se ve bien en desktop (1280px)
  [ ] Sidebar colapsa correctamente en mobile
  [ ] Dashboard cards se reorganizan en mobile
  [ ] Tables son scrollables en mobile

  DARK MODE (Web):
  [ ] Login tiene dark mode funcional
  [ ] Sidebar dark mode
  [ ] Dashboard dark mode
  [ ] Cards, buttons, inputs en dark mode
  [ ] No hay texto ilegible en dark mode
  [ ] No hay bordes invisibles en dark mode

  [ ] Login se ve bien en diferentes tamaños de pantalla
  [ ] Home se ve bien con pocos y muchos action cards
  [ ] QuickPulseBar no se desborda con números grandes
  [ ] Keyboard no tapa inputs en login
  [ ] Safe area funciona correctamente

  RENDIMIENTO:
  [ ] Fuente Inter carga rápido (verificar FCP)
  [ ] Animaciones son smooth (60fps)
  [ ] No hay jank en transiciones de página
  [ ] Dark mode toggle es instantáneo

  ACCESIBILIDAD:
  [ ] Contraste de texto suficiente (WCAG AA)
  [ ] Focus states visibles en todos los inputs
  [ ] Touch targets >= 44px en mobile
  [ ] Screen reader labels en iconos de navegación
