  PLAN DE REDISEÑO UX/UI — SISTEMA PINO
  Resumen Ejecutivo
================================================================================

FECHA:        2026-05-19
SISTEMA:      Pino (Multi-Tienda / Distribución)
PLATAFORMAS:  React Web (Next.js 15) + Flutter Mobile
ALCANCE:      Rediseño visual completo — sin cambios en lógica de negocio

================================================================================
OBJETIVO
================================================================================

Transformar la interfaz actual (que se siente rígida, tipo "PrimeFaces/enterprise")
en una experiencia MODERNA, AMIGABLE, CÁLIDA y FAMILIAR que el usuario operativo
disfrute usar todos los días.

================================================================================
DIAGNÓSTICO GENERAL
================================================================================

PROBLEMAS PRINCIPALES:
  1. Neumorfismo anticuado en login web (sombras inset en inputs)
  2. Colores verde militar (#14532D, #047857) — demasiado serios/fríos
  3. Sidebar tipo admin template — lista plana de 11+ items sin agrupar
  4. Tipografía PT Sans — funcional pero aburrida
  5. Dashboard sin personalidad — solo números sin contexto visual
  6. Sin animaciones — todo aparece de golpe, sin transiciones
  7. Inconsistencia visual — web y Flutter se sienten como sistemas distintos

================================================================================
DECISIONES ESTRATÉGICAS
================================================================================

  FRAMEWORK CSS:     Mantener TailwindCSS 3 + shadcn/ui (se reconfigura, no se cambia)
  TIPOGRAFÍA:        Inter (Google Fonts) — ambas plataformas
  PALETA NUEVA:      Azul vivo #2563EB + Violeta #7C3AED + Ámbar #F59E0B
  ENFOQUE:           Reconfigurar tokens + rediseñar pantallas clave

LO QUE NO SE CAMBIA
================================================================================

  - No se cambia el framework (Next.js, Flutter, NestJS)
  - No se cambia la librería de componentes (shadcn/ui se mantiene)
  - No se cambia TailwindCSS (se reconfiguran los tokens)
  - No se cambia la estructura de rutas ni la lógica de auth
  - No se cambian los providers/context
  - No se cambian las APIs ni el backend
