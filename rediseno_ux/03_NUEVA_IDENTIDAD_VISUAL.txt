PRINCIPIOS DE DISEÑO:

  1. FAMILIAR, NO CORPORATIVO
     Que se sienta como una app que usas todos los días (WhatsApp, Uber),
     no como un ERP o sistema enterprise.

  2. CÁLIDO Y ACOGEDOR
     Colores que transmiten confianza y cercanía, no frialdad.

  3. MINIMALISTA CON PROPÓSITO
     Cada elemento tiene una razón de existir. Nada sobra.

  4. CONSISTENTE CROSS-PLATFORM
     Misma identidad visual en Web y Flutter.

  5. RÁPIDO Y FLUIDO
     Transiciones suaves, feedback inmediato al usuario.

TIPOGRAFÍA
================================================================================

FUENTE ELEGIDA: Inter (Google Fonts)
  - URL: https://fonts.google.com/specimen/Inter
  - Licencia: SIL Open Font License (libre)

¿POR QUÉ INTER?
  1. Diseñada específicamente para pantallas y UI
  2. Excelente legibilidad en tamaños pequeños
  3. 18 pesos disponibles (100-900) — máxima flexibilidad
  4. Soporte tabular de números (ideal para dashboards con cifras)
  5. La usan: GitHub, Figma, Vercel, Linear, Notion
  6. Disponible en google_fonts para Flutter
  7. Variable font = carga rápida

PESOS A USAR:
  - 400 Regular:  Body text, descripciones
  - 500 Medium:   Labels, subtítulos
  - 600 SemiBold: Botones, links activos
  - 700 Bold:     Títulos de sección
  - 800 ExtraBold:Números grandes, headings hero

ESCALAS DE TEXTO:
  - xs:   0.75rem / 12px  (badges, timestamps)
  - sm:   0.875rem / 14px (body secundario, captions)
  - base: 1rem / 16px     (body principal)
  - lg:   1.125rem / 18px (subtítulos)
  - xl:   1.25rem / 20px  (títulos de card)
  - 2xl:  1.5rem / 24px   (títulos de sección)
  - 3xl:  1.875rem / 30px (headings de página)
  - 4xl:  2.25rem / 36px  (hero, números grandes)
